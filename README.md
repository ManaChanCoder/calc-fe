# Simple Calculator project using React + TypeScript + Vite

A simple calculator app built with React and Zustand.
Supports basic operations (+, -, x, /) with 2-decimal precision.

## Features

- First and Second number handling
- Backspace (DEL) function
- Clear Function
- 2 Decimal precision for results

## Usage

- Click number buttons to input numbers.
- Use +, -, x, / for operations.
- Press '=' to compute result.
- Press 'C' to clear or 'DEL' to delete last entry.

## Installation

1. Clone the repo:

```bash
# 1. Git clone the repo:
git clone https://github.com/ManaChanCoder/calc-fe.git

# 2. Go the cal-app directory
cd calc-app

# 3. Install dependencies
npm i or npm install

# 4. Run the project
npm run dev
```
